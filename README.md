# المحاسب — نسخة 1.0

مشروع Android Studio (Kotlin + Jetpack Compose، minSdk 24). يعمل بدون إنترنت.

## التشغيل
1. افتح المجلد في Android Studio (Koala أو أحدث) وانتظر مزامنة Gradle.
2. Run على جهاز أو محاسب. لبناء APK: Build > Build APK(s).
   (ملاحظة: لم يُبنَ المشروع على جهاز المطوّر؛ إن ظهر خطأ بناء بسيط أرسله لتصحيحه.)

## قاعدة البيانات
`assets/schema.sql` و`assets/seed.sql` هما مخطط inv.db كاملاً (جداول + Views + Triggers) مع البيانات الأساسية.
المحرك المحاسبي داخل الـ Triggers، فحفظ فاتورة أو سند يولّد القيود تلقائياً. النسخ الاحتياطي بصيغة inv.db نفسها
(يمكن استرجاع ملفات النسخ القديمة من القائمة الجانبية).

## الميزات
- الرئيسية: المبيعات (+)، المشتريات (+)، قبض/صرف، الحسابات، وقوائم: عمليات مخزنية، قيود وحسابات، أصناف، العملات، التقارير.
- فواتير مبيعات ومشتريات: نقد/آجل، مرتجع، مخزن، عملة، خصم، ضريبة، رسوم أخرى، مدفوع/متبقي، وحدات فرعية (كرتون...).
- قوائم الفواتير مع بحث وعرض التفاصيل وحذف. عرض سعر وطلب شراء.
- سندات قبض/صرف متعددة القيود، قيد يومي، قيد إفتتاحي.
- الحسابات (عملاء، موردون، نقدية، مصروفات، إيرادات، أخرى)، كشف حساب بالعملة، حركة الصندوق، دليل الحسابات.
- المخزون: أصناف، أسعار البيع، وحدات الصنف، توريد وصرف مخزني، تحويل بين المخازن، تسوية، جرد، إضافة مخزن.
- العملات: إضافة عملة، أسعار الصرف، سقف الحساب.
- التقارير: حركة الأصناف، ميزان المراجعة، قائمة الدخل، المركز المالي، أرصدة العملاء والموردين، المخزون المتبقي.
- الإعدادات: البيانات الشخصية، المستخدمون والصلاحيات (تسجيل دخول)، التصنيفات، مجموعة الصنف، وحدات القياس، الضريبة.

## أُضيف في هذا الإصدار
- **إقفال سنوي**: يرحّل الأرصدة الميزانية (عملاء، موردون، صناديق، ضريبة...) وبضاعة آخر المدة لكل مخزن كقيود افتتاحية في اليوم التالي،
  ويرحّل الربح/الخسارة إلى رأس المال، ويحذف الفواتير والسندات حتى تاريخ الإقفال ويقفل الفترة. تُحفظ نسخة احتياطية قبل التنفيذ ويلزم تأكيد بكتابة كلمة.
  (خوارزمية الإقفال اختُبرت على قاعدة SQLite بنفس الـ Triggers: الأرصدة والمخزون تتطابق قبل وبعد، والفترة المقفلة ترفض أي تعديل.)
- **تعديل الفاتورة المحفوظة** (من تفاصيل الفاتورة) بنفس رقمها، بحذف القيود القديمة وإنشاء الجديدة في عملية واحدة.
- **PDF وطباعة**: زر PDF الأحمر في الفواتير وكشف الحساب والتقارير (مشاركة/حفظ أو طباعة النظام). بيانات المنشأة من الإعدادات ← البيانات الشخصية.
- **الطابعة الحرارية بلوتوث (ESC/POS)**: الإيصال يُرسم كصورة فتظهر العربية سليمة؛ عرض 58 أو 80 مم. لم تُجرَّب على طابعة فعلية.
- **طباعة باركود الأصناف**: ملصقات Code128 في PDF (A4، 27 ملصق بالصفحة).
- **قفل التطبيق** برمز (وبصمة اختيارية)، ويُقفل بعد دقيقة في الخلفية.
- **الإشعارات**: جرس الرئيسية يعرض نفاد/انخفاض المخزون والاقتراب من سقف الحساب، مع خيارات التفعيل.
- **حفظ البيانات**: نسخة تلقائية عند الخروج (آخر 7)، نسخ محلية يمكن استرجاعها، و"جوجل درايف" عبر قائمة المشاركة.
- **تقارير بعملة مختارة**: ميزان المراجعة وقائمة الدخل والمركز المالي. عدد الخانات العشرية من "خيارات أخرى".
- رسائل أخطاء عربية (السنة المقفلة، سقف الحساب...).

## غير موجود
الرفع المباشر إلى Google Drive عبر API (يحتاج مفاتيح حساب Google Cloud خاص بك؛ البديل الحالي المشاركة)، شاشة "التواصل والدعم"،
"تفعيل الاشتراك"، الفاتورة الإلكترونية (حقول z_ في القاعدة)، تصدير Excel. قيمة المخزون في الدخل/المركز المالي تقديرية بآخر سعر شراء وبالعملة المحلية فقط.
المشروع لم يُبنَ على جهاز مطوّر؛ أرسل أي خطأ بناء يظهر لتصحيحه.
